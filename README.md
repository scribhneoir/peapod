# Peapod

## Description

Peapod is a podcast browser and player for the Panic Playdate

## Setup

### Prerequisites

- [Lua 5.5](https://www.lua.org/start.html)
- [Panic Playdate SDK](https://play.date/dev/)

### Clone

```sh
git clone --recursive https://github.com/scribhneoir/peapod.git
cd peapod
```

### Build

```sh
pdc src dist/peapod
```
